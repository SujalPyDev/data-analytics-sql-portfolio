# Contributing

Thanks for your interest in improving this project! To contribute:

1. Fork the repository and create a new branch for your change.
2. Open an issue describing the problem or feature you want to add.
3. Make your changes on the branch and open a Pull Request back to the main repository.
4. Keep changes focused and include tests or sample data when applicable.

Please avoid uploading real, sensitive, or copyrighted datasets. Use synthetic or public-domain data when adding examples.
