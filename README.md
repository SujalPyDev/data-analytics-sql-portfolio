# Data Analytics SQL Portfolio

A professional SQL portfolio project focused on analyzing the data analyst job market: top-paying roles, in-demand skills, and high-value skill combinations.

## Project Overview

This repository showcases end-to-end SQL analysis using structured, recruiter-friendly project organization.  
The goal is to answer practical career-focused questions using real job posting data and communicate findings clearly.

## Tools & Technologies

- **SQL (PostgreSQL syntax)** for querying and analysis
- **DBMS / SQL Editor** for execution and exploration
- **Git & GitHub** for version control and portfolio presentation

## Analysis Questions

This project answers five core questions:

1. [Which data analyst jobs pay the most?](./practice_project_sql/1. top_paying_jobs.sql)
2. [What skills are required for top-paying analyst jobs?](./practice_project_sql/2. top_paying_skills.sql)
3. [Which skills are most in demand for data analysts?](./practice_project_sql/3. in_demand_skills.sql)
4. [Which skills are associated with higher average salaries?](./practice_project_sql/4. top_salary_based_skills.sql)
5. [What are the most optimal skills (high demand + high pay)?](./practice_project_sql/5. most_optimal_skills.sql)

## Key Insights

- Remote and senior analyst roles tend to offer the highest compensation.
- Skills like SQL, Python, and cloud/data tooling frequently appear in high-paying postings.
- The best career leverage comes from skills that are both highly demanded and salary-advantaged.

## How to Use

1. Open any query from `practice_project_sql/`.
2. Run it against the target jobs dataset in your SQL environment.
3. Save visual outputs (charts/tables) in `assets/` for portfolio screenshots.
