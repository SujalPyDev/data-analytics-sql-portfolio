## Project Overview

This repository presents end-to-end SQL analysis built for recruiter-friendly review.  
The project turns raw job-posting data into practical insights that support career and upskilling decisions.

## Tools & Technologies

- **SQL (PostgreSQL syntax)** for querying and analysis
- **DBMS / SQL editor** for execution and exploration
- **Git & GitHub** for version control and presentation

## Key Insights

- The highest salaries are concentrated in remote and senior-oriented analyst roles.
- SQL and Python consistently appear across top-paying opportunities.
- The best learning strategy balances **market demand** with **salary upside**.
