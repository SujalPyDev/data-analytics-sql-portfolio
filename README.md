A recruiter-friendly SQL portfolio focused on the Data Analyst job market. This project demonstrates structured analytical thinking through clear business questions, production-style SQL organization, and concise insight communication.

## Project Overview

This portfolio analyzes job posting data to identify:
- where the highest-paying Data Analyst opportunities are,
- which skills are required for top-paying roles,
- which skills are most in demand,
- which skills are associated with higher salary outcomes,
- and which skills are most optimal when balancing demand and pay.

The repository is intentionally organized for quick review by recruiters, hiring managers, and peers.

## Tools & Technologies

- **SQL (PostgreSQL syntax)** — querying, joins, aggregations, and CTE-based analysis
- **DBMS / SQL Editor** — query execution and result exploration
- **Git & GitHub** — version control and portfolio presentation

## Key Insights

- Top-paying remote Data Analyst roles tend to cluster around senior and specialized profiles.
- SQL and Python appear consistently across high-compensation opportunities.
- The strongest upskilling strategy prioritizes skills that score well in both demand and salary impact.
