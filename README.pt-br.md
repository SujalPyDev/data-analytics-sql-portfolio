Um portfólio SQL orientado para recrutadores, focado no mercado de trabalho para Data Analysts. Este projeto demonstra raciocínio analítico estruturado com perguntas de negócio claras, organização profissional dos arquivos SQL e comunicação objetiva dos insights.

## Visão Geral do Projeto

Este portfólio analisa dados de vagas para identificar:
- onde estão as oportunidades de Data Analyst com maior salário,
- quais habilidades são exigidas nas vagas mais bem pagas,
- quais habilidades estão mais em demanda,
- quais habilidades se associam a salários médios mais altos,
- e quais habilidades são mais estratégicas ao equilibrar demanda e remuneração.

O repositório foi organizado intencionalmente para revisão rápida por recrutadores, gestores de contratação e pares técnicos.

## Ferramentas e Tecnologias

- **SQL (sintaxe PostgreSQL)** — consultas, joins, agregações e análises com CTEs
- **SGBD / Editor SQL** — execução das consultas e exploração dos resultados
- **Git & GitHub** — controle de versão e apresentação do portfólio

## Principais Insights

- As vagas remotas de Data Analyst com maior remuneração tendem a concentrar perfis seniores e especializados.
- SQL e Python aparecem de forma recorrente nas oportunidades com maior faixa salarial.
- A melhor estratégia de desenvolvimento prioriza habilidades com alta demanda e alto impacto salarial.
